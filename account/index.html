Как подключиться

Выберите платформу, чтобы открыть страницу приложения:

iPhone / iPad Android Windows macOS Linux
  1. Установите приложение для своего устройства по ссылке выше.
  2. В карточке подключения нажмите «Скопировать ключ».
  3. В приложении добавьте подключение по ключу, вставьте ссылку vpn:// и нажмите «Подключить».
